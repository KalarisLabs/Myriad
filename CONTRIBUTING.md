# Contributing

Contributions should improve correctness, provenance, routing clarity, or validation without overstating scientific readiness.

## Required for task changes

1. Identify the exact node ID and intended decision context.
2. Explain the evidence supporting the change.
3. Prefer current primary sources and controlled standards.
4. Preserve computational-advisory boundaries and no-call behavior.
5. Add or update tests.
6. Run `npm test` and `python scripts/validate_release.py`.

Do not convert a taxonomy node into an operational laboratory, clinical, manufacturing, or regulatory instruction without qualified review, explicit authorization boundaries, and a separately reviewed `SKILL.md` implementation.
