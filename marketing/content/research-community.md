# Research-community post

MYRIAD is an attempt to make agentic biotech work more legible.

The release maps 100 domains into 10,000 atomic task nodes, each with a stable identity, routing language, provenance expectations, completion evidence, safety boundaries, and explicit no-call conditions. The graph covers genomics, multi-omics, structural biology, drug discovery, advanced therapeutics, biomanufacturing, clinical development, regulatory science, and data governance.

The intent is not to replace scientific judgement or package speculative outputs as established procedures. MYRIAD separates taxonomy maturity from operational skill maturity: the 10,000 nodes describe the work; reviewed `SKILL.md` implementations define how agents should perform it.

The repository includes raw, canonical, and sanitized distributions, per-node Markdown, schemas, validators, an NPX-compatible CLI, and three seed skills.

Created by Srihari Muralikrishnan with ChatGPT for Kalaris Labs. Constructive scientific and systems feedback is welcome.
