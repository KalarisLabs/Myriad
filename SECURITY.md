# Security policy

Report suspected security, privacy, data-integrity, biosafety, biosecurity, or supply-chain issues privately to the repository maintainers before public disclosure.

Do not submit sensitive patient data, proprietary sequences, credentials, controlled manufacturing records, export-controlled content, or actionable harmful biological instructions in public issues.

The CLI is intentionally dependency-free and performs local read-only access to bundled taxonomy data except when the user explicitly invokes `export` or `init`.
