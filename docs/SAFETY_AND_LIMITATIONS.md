# Safety and limitations

MYRIAD supports computational planning, validation, evidence synthesis, and reporting.

It must not autonomously:

- execute or optimize wet-lab protocols;
- design harmful biological agents or evade biosafety controls;
- prescribe treatment or issue unreviewed patient-specific conclusions;
- control bioreactors or manufacturing equipment;
- approve deviations, release GMP lots, or assert compliance;
- replace institutional, clinical, regulatory, biosafety, or biosecurity review.

Every node requires an explicit no-call when evidence, provenance, applicability, or authorization is insufficient.
