# Roadmap

## Completed

- Phase 1: 100-domain master index.
- Phase 2: 100 atomic tasks per domain, 10,000 total.
- Release engineering: canonical schema, per-node Markdown, CLI, validators, sanitized distribution, and archives.

## Next

- Phase 3: convert selected nodes into reviewed `SKILL.md` implementations in batches of ten.
- Add task-specific primary-source manifests and evaluation fixtures.
- Add domain-expert review states and signed approvals.
- Add benchmark suites for routing accuracy, completion quality, calibration, and safe no-call behavior.
